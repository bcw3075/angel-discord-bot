# House rules (example)

Copy this file to `house-rules.md` beside `package.json` and write your table's own rules in it. Angel reads it with
every question, and a house rule wins over Archives of Nethys. Everything Angel says is heard by the players, so keep
GM-only secrets out of this file.

- Example: Hero Points: everyone starts each session with 2.
- Example: Critical fumble cards are not used.
